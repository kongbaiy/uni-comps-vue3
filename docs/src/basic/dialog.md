# Popover

## Props

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-------|-------|-------|-------|-------|
| title | 标题 | string | - | - |
| modelValue | 绑定值 | string/number | -  | - |
| showMask | 显示遮罩 | boolean | `true` `false` | `true` |
| maskClose | 点击遮罩关闭 | boolean | `true` `false` | `false` |
| contentHeight | 点击遮罩关闭 | boolean | `true` `false` | `false` |
| contentPadding | 点击遮罩关闭 | boolean | `true` `false` | `false` |
| cancelText | 点击遮罩关闭 | boolean | `true` `false` | `false` |
| confirmText | 点击遮罩关闭 | boolean | `true` `false` | `false` |

## Slots

| 插槽名称 | 说明 | 参数 | 类型 |
|-------|-------|-------|-------|
| header | 自定义头部 | - | - |
| icon | 自定义 icon | - | - |
