# Text 文本

## Props

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-------|-------|-------|-------|-------|
| content | 文本内容 | string | - | - |
| lineClamp | 行数 | number | -  | `1` |
| lineHeight | 行高 | number | -  | - |
| expandText | 展开文字 | string | -  | `展开` |
| collapseText | 收起文字 | string | -  | `收起` |
| color | 颜色 | string | -  | - |

## Slots

| 插槽名称 | 说明 | 参数 | 类型 |
|-------|-------|-------|-------|
| content | 文本内容 | - | - |
| expand | 自定义展开 | isExpand | boolean |
