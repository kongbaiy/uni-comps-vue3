# VerifyCode 验证码

## Props

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-------|-------|-------|-------|-------|
| text | 文字 | string | - | `获取验证码` |
| delay | 验证码延时时间，默认单位秒 | number | -  | `60` |
| width | 按钮宽度 | string | -  | - |
| height | 按钮高度 | string | -  | - |

## Events

| 事件名称 | 说明 | 参数 | 返回值 |
|-------|-------|-------|-------|
| start | 触发验证码延时，返回一个函数手动调用 | `next` | - |
