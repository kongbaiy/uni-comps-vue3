# Textarea 多行文本框

## Props

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-------|-------|-------|-------|-------|
| disabled | 禁用 | boolean | `true` `false`  | `false` |
| modelValue | 绑定值 | string | -  | - |
| wordNumber | 显示字数统计 | boolean | `true` `false`  | `false` |
| maxlength | 输入长度限制 | number | - | - |
| placeholder | 提示文字 | string | -  | - |
| placeholderStyle | 提示文字样式 | string | - | - |
| padding | 内边距 | string | -  | `12rpx 20rpx` |
| height | 高度 | string | -  | `240rpx` |
| borderColor | 边框颜色 | string | -  | - |
| radius | 倒圆角 | string | -  | `8rpx` |
