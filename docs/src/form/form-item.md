# FormItem 表单项

## Props

| 参数 | 说明 | 类型 | 可选值 | 默认值 |
|-------|-------|-------|-------|-------|
| prop | 字段名 | string | -  | - |
| label | label 文字 | string | -  | - |
| required | 是否必传 | boolean | -  | - |
| layout | 表单项布局 | string | `left` `right` `top`  | - |
| prompt | 消息提示方式 | string | `toast` `message`  | `message` |
| labelWidth | label 宽度 | string | -  | - |
| labelGap | label 间隔 | string | -  | - |
| align | label 对齐方式 | string | `left` `right` `justify` | - |
| border | 是否显示边框 | boolean | `true` `false` | `false` |
